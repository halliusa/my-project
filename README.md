# Сандевистан: Апогей (Sandevistan: Apogee)

Fabric-мод для Minecraft Java 1.20.1 по мотивам аниме «Киберпанк: Бегущие по краю».
Имплант в **отдельном нейрослоте** (клавиша `C`), активация клавишей `V`, ускорение игрока, замедление мобов и снарядов вокруг, послесвечения-силуэты, ударная волна, электрические дуги, кинематографичная «перегрузка» при активации, HUD и звуки.

## Что нового в 1.1.0

* **Отдельный слот для Сандевистана.** Имплант больше не нужно таскать в инвентаре: нажмите `C` (или кнопку с иконкой импланта в экране инвентаря) — откроется панель «НЕЙРОИМПЛАНТ», куда имплант вставляется в отдельный слот. Для активации нужен именно он (старое поведение — в конфиге сервера, `allowInventoryActivation`). Нейрослот привязан к игроку: содержимое хранится в файле мира (`data/sandevistan_apogee_implants.dat`), переживает смерть, перезаход, смену измерения и рестарт сервера. При смерти имплант в слоте не выпадает (в отличие от обычных предметов).
* **Улучшенные экранные эффекты**: лёгкий зелёный «визор» с медленными сканлайнами и плывущей полосой, красное сердцебиение-виньетка в последние 1.5 секунды работы (и красный таймер в HUD), скоростные линии теперь реально «летят» наружу от центра.
* HUD честно показывает состояние: «имплант в инвентаре, но не установлен в слот» подсказывает нажать `C`.
* Новые тумблеры: `/apogeefx tint`, `/apogeefx lowtime`.
* Звук установки/извлечения импланта (короткое «вжух»).

## Управление

* `V` — активировать Сандевистан (переназначается: Настройки → Управление → «Сандевистан: Апогей»).
* `C` — открыть панель «НЕЙРОИМПЛАНТ» (переназначается там же). Имплант кладётся в отдельный слот внутри этой панели. Открыть её можно и кнопкой в экране инвентаря (верхний правый угол, иконка импланта, подсказка: hover-текст; если кнопка не появилась — миксин не применился, клавиша работает всегда).
* «Переключить интенсивность визуальных эффектов» — по умолчанию не назначена. Циклично: 0 / 35 / 65 / 100 %.
* Имплант должен быть **установлен в нейрослот**. Если он лежит просто в инвентаре, HUD покажет «НЕ В СЛОТЕ [C]», а `V` подскажет, что делать.

Крафт (шаблон):

```
D R D     D = алмаз
N C N     R = блок редстоуна, N = незеритовый слиток
L E L     C = часы, L = громоотвод, E = око Эндера
```

В творческом режиме: вкладка «Кибернетика». Команда: `/give @s sandevistan_apogee:sandevistan_apogee`.

## Как работает

* Клиент отправляет **пустой** запрос. Сервер сам проверяет наличие импланта в нейрослоте, активное состояние и перезарядку.
* Нейрослот — отдельная 1-слоточная инвентарь-ячейка на игрока, сериализуется в `data/sandevistan_apogee_implants.dat` внутри папки мира (только на сервере). При смерти, перезаходе, переходе в портал и рестарте имплант остаётся в слоте. Содержимое HUD-у синхронизируется пакетом при установке/извлечении и при входе на сервер.
* Ускорение и скорость атаки — временные атрибут-модификаторы с фиксированными UUID. Повторная активация во время действия игнорируется, поэтому ничего не накапливается.
* Мобы в радиусе получают ванильное «Замедление» (короткое, обновляется каждые 4 тика, скрытое), снаряды не от игроков ограничиваются по скорости. Владелец, его питомцы, его снаряды и другие игроки не затрагиваются (игроков можно включить в конфиге).
* Скорость мира (tick rate) не меняется, потоки не блокируются.
* Эффект сбрасывается при: окончании времени, смерти, выходе, смене измерения, респавне, потере импланта из инвентаря. Затем начинается перезарядка (она переживает перезаход).
* След на других клиентах: сервер шлёт старт/конец и «обновление» раз в 10 тиков; снимки позиций клиент делает сам, никаких пакетов каждый кадр.
* Послесвечения рисуются клиентом: ванильная модель игрока с полупрозрачным эмиссивным слоем, цвет от голубого к красному. Скин не меняется, сущности не создаются.
* Экранные эффекты — на обычном HUD-слое, без полноэкранного шейдера (надёжный fallback, нет конфликтов с шейдерпаками).

## Настройки

### Сервер: `config/sandevistan_apogee.json` (перечитывается `/sandevistan reload`)

| Ключ | По умолчанию | Описание |
|---|---|---|
| `durationSeconds` | 5.0 | длительность эффекта, с |
| `cooldownSeconds` | 30.0 | перезарядка (после окончания эффекта), с |
| `radius` | 24.0 | радиус замедления, блоков |
| `speedBonus` | 1.2 | бонус скорости (1.2 = +120 % от итоговой) |
| `attackSpeedBonus` | 0.35 | бонус скорости атаки |
| `mobSlownessAmplifier` | 3 | уровень «Замедления» мобам (0 = I, 3 = IV) |
| `projectileMaxSpeed` | 0.9 | максимум скорости чужих снарядов, блоков/тик (стрела ~3). Медленные стрелы наносят меньше урона |
| `affectPassiveMobs` | true | замедлять и мирных мобов |
| `affectPlayers` | false | замедлять других игроков и их снаряды |
| `allowInventoryActivation` | false | legacy: имплант работает и просто лежа на инвентаре (без установки в нейрослот) |
| `playLoopSound` | true | «гул» раз в секунду |

### Клиент: `config/sandevistan_apogee_client.json` или команда `/apogeefx`

| Ключ / команда | По умолчанию | Описание |
|---|---|---|
| `intensity` / `/apogeefx intensity 0..1` | 1.0 | общая сила эффектов (0 = всё выключено, HUD остаётся) |
| `cameraShake` / `shake` | true | лёгкая тряска камеры |
| `cameraFov` / `fov` | true | мягкий импульс FOV |
| `screenFlash` / `flash` | true | вспышка (максимум 30 % яркости, плавное затухание) |
| `screenOverlay` / `overlay` | true | виньетка и линии скорости |
| `screenTint` / `tint` | true | зелёный «визор»: виньетка-tint, медленный сканлайн и плывущая полоса |
| `lowTime` / `lowtime` | true | красная пульсация краёв экрана и красный таймер в последние 1.5 с |
| `afterimages` | true | послесвечения игрока |
| `arcs` | true | электрические дуги |
| `particles` | true | искры |
| `hud` | true | панель HUD |
| `hudAnchor`, `hudOffsetX/Y` | BOTTOM_RIGHT, 10, 10 | положение HUD (TOP_LEFT, TOP_RIGHT, BOTTOM_LEFT, BOTTOM_RIGHT) |

Ничего не мерцает: все эффекты затухают экспоненциально или следуют медленной синусоиде, случайного шума по кадрам нет.

## Звуки

В проекте **нет** оригинальных звуков Cyberpunk. По умолчанию `sounds.json` использует ванильные звуки как заглушки.

Свои звуки (OGG Vorbis, **моно**):

```
src/main/resources/assets/sandevistan_apogee/sounds/sandevistan/activate.ogg     — активация
src/main/resources/assets/sandevistan_apogee/sounds/sandevistan/loop.ogg         — работа (коротко, раз в секунду)
src/main/resources/assets/sandevistan_apogee/sounds/sandevistan/deactivate.ogg   — отключение
src/main/resources/assets/sandevistan_apogee/sounds/sandevistan/ready.ogg        — готовность после перезарядки
```

Затем выполните `python generate_assets.py --use-custom-sounds`. Скрипт проверит, что все 4 файла на месте, и перепишет `sounds.json`.
Громкость каждого звука задаётся в `sounds.json` (`volume`). Категория — «Игроки»; звук позиционный (слышен рядом с владельцем).
События: `sandevistan_apogee:sandevistan.activate|loop|deactivate|ready`.

## Сборка

```
python generate_assets.py          # PNG-текстуры (один раз)
gradle wrapper --gradle-version 8.8   # один раз: создаёт gradlew, gradlew.bat и gradle-wrapper.jar
./gradlew build                    # Windows: .\gradlew.bat build
./gradlew runClient                # клиент разработки
```

Готовый мод: `build/libs/sandevistan-apogee-1.1.0.jar`.

## Проверочный список

**Одиночная игра**
- [ ] предмет есть в вкладке «Кибернетика», рецепт работает, названия ru/en;
- [ ] `C` открывает панель «НЕЙРОИМПЛАНТ», клик/шифт-клик кладёт имплант в нейрослот, звук «вжух»;
- [ ] кнопка с иконкой импланта в правом верхнем углу экрана инвентаря тоже открывает панель;
- [ ] имплант в слоте → `V` работает, HUD меняется; имплант вынут из слота → эффект гаснет в течение секунды, повторный `V` пишет «не установлен»;
- [ ] имплант в инвентаре, но НЕ в нейрослоте → HUD серый «НЕ В СЛОТЕ [C]», `V` подсказывает установку;
- [ ] другой предмет в нейрослот не вставляется;
- [ ] без предмета `V` пишет «нужен имплант»;
- [ ] клавиши `V` и `C` есть в настройках управления и переназначаются;
- [ ] в последние 1.5 с эффекта красная пульсация краёв и красный таймер;
- [ ] 5 с ускорения, затем отключение (синяя волна, звук);
- [ ] повторное `V` во время действия не усиливает эффект;
- [ ] мобы вокруг замедлены, их стрелы медленные, владелец и его стрелы — нет;
- [ ] пауза не ломает таймер HUD.

**Dedicated server**
- [ ] сервер стартует без ошибок про клиентские классы;
- [ ] второй игрок видит силуэты, волну и слышит звук;
- [ ] эффект работает только при импланте, установленном в нейрослот (проверка на сервере);
- [ ] второй игрок, поставивший мод, видит панель/HUD корректно; имплант одного игрока не активирует эффект другому;
- [ ] `/sandevistan reload` перечитывает конфиг (включая `allowInventoryActivation`).

**Смерть / выход / измерение / сохранение**
- [ ] смерть во время эффекта: скорость обычная после респавна, HUD в перезарядке; имплант остаётся в нейрослоте;
- [ ] выход и возврат: скорость обычная, перезарядка не сбрасывается; имплант на месте;
- [ ] портал: эффект завершён, запущена перезарядка; имплант на месте;
- [ ] перезапуск мира / сервера: установленные импланты всех игроков на месте (файл `data/sandevistan_apogee_implants.dat`);
- [ ] `/clear` по игроку не трогает имплант в нейрослоте (как и `/kill` не удаляет его).

**После окончания и перезарядка**
- [ ] через 5 с: модификаторы сняты, нет остаточного замедления у мобов;
- [ ] во время перезарядки HUD голубой, `V` показывает остаток;
- [ ] через 30 с: сигнал «READY», звук, HUD пульсирует; повторная активация работает;
- [ ] `/apogeefx intensity 0`, `shake false`, `flash false`, `overlay false`, `tint false`, `lowtime false` отключают соответствующее.

## Известные ограничения

* Сборка и запуск не выполнялись автором исходников — проверьте у себя (см. раздел «Что проверено» на странице).
* Миксины (`CameraMixin`, `GameRendererMixin`, `ScreenInitMixin`, `HandledScreenForegroundMixin`) имеют `defaultRequire: 0`: при несовпадении сигнатуры они отключаются, а мод продолжает работать (без тряски/FOV или без кнопки в инвентаре; клавиша `C` и панель работают всегда).
* Кнопка в экране инвентаря сидит в правом верхнем углу панели; при очень больших кастомных GUI-масштабах/шейдерах она может визуально смещаться относительно панели — клавиша `C` везде заменяет её.
* Имплант привязан к миру (файл в папке мира): он не «перетекает» между разными мирами/серверами ванильным образом. Для пары клиент-сервер это нормально.
* Замедленные снаряды наносят меньше урона (урон стрелы зависит от скорости).
